# 🎮 ArenaForge

ArenaForge is a real-time 2D multiplayer battle arena game built to learn production-level backend engineering.

## 🚀 Goal

This project is focused on learning:

- FastAPI
- Async Programming
- WebSockets
- JWT Authentication
- PostgreSQL
- SQLAlchemy
- Redis
- Docker
- Clean Architecture
